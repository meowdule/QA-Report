사이트 분석 · 시나리오 테스트

한 화면에서 분석 → 결과 확인 → 시나리오 조정 → 재테스트까지 진행합니다. 작업마다 번호가 새로 생겨 서로 다른 분석 결과가 섞이지 않습니다.

바로가기 요약 테스트 결과 시나리오 목록 수정 · 재실행 수집한 페이지 리포트

1 새 사이트 분석

HTTPS 페이지 URL을 입력한 뒤 분석을 시작하세요.

실행 기록(트레이스)

문제가 났을 때 화면 흐름을 다시 볼 수 있게 저장합니다. 보통은 실패한 경우만 저장하면 충분합니다.

분석에는 수 분 걸릴 수 있습니다. 진행 중에는 이 탭을 닫지 마세요.

2 예전에 받은 작업 번호로 열기 (선택)

주소 끝에 ?job=번호가 있으면 자동으로 불러옵니다. 번호만 알고 있을 때 여기 입력해 주세요.

자동으로 만든 점검 묶음입니다. 아래 「수정」에서 순서와 내용을 바꿀 수 있습니다.

3 시나리오 수정 · 다시 테스트

블록을 위아래로 옮기거나 삭제해 순서를 바꾸고, 칸에 값을 적어 내용을 수정합니다. 같은 작업 번호로 다시 돌립니다.
